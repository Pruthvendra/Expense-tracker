## Is it Safe?

Yes. This is a single HTML file that runs in your browser. It does **not**:
- Install anything on your computer
- Access your files, camera, or microphone
- Send data to any server
- Require sign-up or permissions

Your data stays on your device using the browser's built-in storage.

&gt; Some antivirus software may flag HTML files with JavaScript as a "script" warning. This is a **false positive** — the same technology powers every website you visit.
