🛡️ Is it Safe?
Yes. This is a single HTML file that runs entirely in your browser. It does NOT:
Install anything on your computer
Access your files, camera, or microphone
Send data to any server or cloud
Require sign-up or permissions
Your data is stored using your browser's built-in localStorage — it never leaves your device.
⚠️ Note: Some antivirus software may flag HTML files containing JavaScript as a "script" warning. This is a false positive — the same technology (JavaScript) powers every website you visit. This file cannot harm your device.
